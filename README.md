# 玩法介绍

### 安装教程
下载发行版
或在[https://starsunion.top/game/2/index.html](http://)在线试玩

### 使用说明
基本玩法:玩家控制红色数字，在布满灰色数字的网格中移动，通过吞噬敌人和灰色数字不断壮大自己。游戏包含经典模式和高级模式，敌人拥有智能行为，后期还会分裂和加速，挑战性十足。

###  玩法简介

目标：吞噬所有蓝色敌人，同时避免被数值更大的敌人吞噬。
操作：使用键盘 WASD 控制红色数字移动（上下左右）。

网格：游戏区域由 H×W 个方格组成，每个方格显示一个数字。

暂停：按 P 键可暂停游戏，并选择重新开始或继续。

###  游戏规则

1, **基本元素** 
红色数字：玩家，初始值为 2。

蓝色数字：敌人，初始值为 2。

灰色数字（1）：中立资源，可被玩家或敌人吞噬，使吞噬者数值 +1。

空白格子（0）：可移动的空地，无任何效果。

2, **移动规则** 

- 玩家移动：按 WASD 向相邻格子移动。
- 
- 移动到灰色1：玩家数值 +1，该格子变为空白（0），玩家留在原地。
- 
- 移动到空白0：玩家直接移动到该格子，原格子变为空白。
- 
- 移动到敌人：发生战斗，比较双方数值。
- 
- 若玩家数值 > 敌人数值：玩家吞噬敌人，获得敌人全部数值，格子变为玩家。
- 
- 若玩家数值 ≤ 敌人数值：玩家被吞噬，游戏失败。
- 
- 敌人移动：所有敌人自动定时移动（移动间隔由玩家在开始界面设置的“Speed of Enemies”决定）。每个敌人移动时会根据智能决策选择一个方向（上、下、左、右之一），并执行类似玩家的移动逻辑：
- 
- 移动到灰色1：敌人数值 +1，格子变空白，敌人原地不动。
- 
- 移动到空白0：敌人移动到该格子，原格子变空白。
- 
- 移动到玩家：发生战斗，判定与玩家移动时一致。
- 
- 移动到其他敌人：被阻挡，不移动。


3, **灰色数字刷新** 
当空白格子（数值0）的数量超过总格子数的 1/3 时，系统会随机选择一个空白格子，将其数值设为 1（灰色数字）。这保证了资源持续再生，游戏不会陷入僵局。

4, **胜利与失败** 
胜利条件：所有敌人被吞噬（敌人数量为 0）。

失败条件：玩家被任何敌人吞噬。

5, **玩家技能** 
吞噬成长：吞噬灰色数字或敌人后，玩家数值会增长，数值越高越有优势。
策略移动：玩家需要权衡是优先吃灰色数字壮大自己，还是主动追击弱小的敌人，同时要躲避强敌。

### 敌人技能（智能AI）

所有敌人均采用混合智能决策，根据自身数值与玩家数值的关系，以及距离远近，采取不同行为：

1. 基础智能（适用于两种模式）
当敌人数值 ≥ 玩家数值：主动向玩家靠近（选择曼哈顿距离减小的方向）。

当敌人数值 < 玩家数值：

若与玩家的曼哈顿距离 < 15：向远离玩家的方向逃跑（选择距离增大的方向）。

若与玩家的曼哈顿距离 ≥ 15：
使用广度优先搜索（BFS）寻找最近且与玩家距离≥15的灰色数字（1），并朝该方向移动，优先觅食增强自己。

2. 高级模式专属技能
动态加速：玩家每获得 10分（即玩家数值比初始值2每增加10），所有敌人的移动速度增加 0.05（初始速度由玩家输入）。这意味着游戏越后期，敌人行动越快，挑战性逐渐提升。

分裂：当任一敌人的数值 **大于** 玩家数值的2倍 *或* 敌人分数小于玩家分数,玩家与敌人的曼哈顿距离小于5,敌人累计分裂次数小于2次且敌人的分数大于8 ，该敌人会尝试分裂成两个新敌人，分数均分（总和不变）。分裂位置优先选择原格子及相邻空白格子，确保两个新敌人能同时存在。分裂后，敌人数量增加，玩家需要面对更多对手。

### 开始界面与设置

游戏启动后，选择Classic Mode或Advanced Mode。

进入设置界面，输入四个参数：

Height (H)：网格行数

Width (W)：网格列数

Amount of Enemies (E)：初始敌人数

Speed of Enemies：敌人每秒移动次数（例如输入5表示每秒移动5次，即间隔0.2秒）

点击 Start Game 开始游戏。

 **控制与界面** 
WASD或鼠标点击屏幕(点击玩家的前后左右,手机端操作同理)或单击屏幕(手机网页端)：移动玩家

P或双指捏合屏幕(手机网页端)：暂停游戏（弹出菜单可选择 Restart(重新开始) 或 Back(返回游戏)）

游戏窗口支持自由调整大小，网格和文字会自动适应窗口尺寸。

### 小贴士

初期尽量多吞噬灰色数字快速提升数值，再与敌人交锋。

注意敌人分裂条件，数值差距过大时尽量回避。

在高级模式中，随着你的成长，敌人也会越来越快，需要更灵活的走位。
